# Gemini ChatBot

Um chatbot inteligente usando Google Gemini e LangChain com interface Rich.

## 🚀 Como usar

1. **Configure a API Key:**
   ```bash
   # Edite o arquivo .env e adicione sua chave
   GOOGLE_API_KEY=sua_chave_aqui

2. Preparar o ambiente virtual

3. Carregar as dependências

```bash
pip3 install -r requirements.txt
```

4. Executar a aplicação principal

```bash
python3 main.py
```
